# Security Policy

Please do not report a suspected security vulnerability in a public GitHub
issue.

Send a private report to **opensource@hesaitech.com** with:

- the affected branch, commit, and release (if applicable);
- the environment and dependency versions;
- reproduction steps or a proof of concept;
- the expected impact; and
- any suggested mitigation.

Ordinary build, configuration, mapping-quality, and driver-compatibility
problems should use the public bug-report template instead.
